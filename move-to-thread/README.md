# Move to Thread

여러 메시지를 골라 다른 메시지의 답글로 한 번에 옮기는 Mattermost 플러그인입니다.

## 쓰는 법

1. 옮길 메시지에 마우스를 올리고 툴바의 체크 상자 버튼(**답글로 옮길 메시지로 선택**)을 누릅니다. 메시지가 강조되고 화면 아래에 선택 막대가 뜹니다.
2. 선택 막대가 떠 있는 동안 같은 채널의 다른 메시지를 누르면 선택에 더하거나 뺍니다. 링크·버튼·이미지를 누르거나 글자를 끌어 고른 경우는 선택으로 치지 않습니다.
3. 답글을 넣을 메시지에 마우스를 올리고 툴바의 + 말풍선 버튼(**선택한 메시지를 여기 답글로 넣기**)을 누릅니다. 선택 막대에서 **옮기기**를 누르면 옮긴 뒤 그 글타래가 오른쪽에 열립니다.

대상이 답글이면 그 글타래의 맨 위 메시지 아래로 넣습니다. 선택한 메시지에 답글이 달려 있으면 그 답글도 함께 옮깁니다. 다른 채널로 가거나 선택 막대의 **취소**를 누르면 선택이 비워집니다. 실패하면 선택은 그대로 두고 막대에 이유를 보여 줍니다.

## 옮기는 방식

메시지를 새로 만들거나 지우지 않고, 원래 메시지가 속한 글타래만 바꿉니다. Mattermost API에는 이 기능이 없어서, 플러그인이 Mattermost DB의 해당 칸을 한 트랜잭션 안에서 직접 고칩니다. PostgreSQL에서만 동작합니다.

- 메시지 ID, 링크, 작성자, 본문, 첨부 파일, 반응, 공지 여부, 편집 기록이 그대로 남습니다.
- 새 글이 생기지 않으므로 푸시·이메일·데스크톱 알림이 가지 않습니다. 멘션 수와 채널의 안 읽은 메시지 수도 그대로입니다.
- 글타래의 맨 위 메시지보다 먼저 쓴 메시지는 맨 위 메시지 바로 뒤 시각으로 바꿉니다. 그래야 글타래가 위에서 아래로 읽힙니다. 이런 메시지끼리의 순서는 그대로입니다.
- 글타래 표(답글 수, 마지막 답글 시각, 참여자)를 다시 계산합니다. 대상 글타래, 옮긴 답글이 있던 글타래가 모두 대상입니다. 답글이 된 원래 맨 위 메시지의 글타래 기록과 구독 기록은 지웁니다.
- 옮긴 메시지의 작성자와 대상 글타래의 맨 위 작성자는 그 글타래를 구독합니다. 이미 읽은 것으로 표시되므로 안 읽음이 생기지 않습니다.
- 옮긴 뒤 채널에 알리면, 이 플러그인이 켜진 화면은 새로고침 없이 바뀐 자리를 반영합니다.
- 하나라도 고치지 못하면 트랜잭션을 되돌려 아무것도 바뀌지 않습니다.

## 권한

옮기기는 메시지의 자리를 바꾸는 일이라 지울 권한이 있는 메시지만 옮깁니다.

- 옮기는 사람이 그 채널의 멤버이고 글을 쓸 수 있어야 합니다.
- 내 메시지는 `delete_post`, 다른 사람 메시지는 `delete_others_posts` 권한이 있어야 합니다.
- 선택한 메시지와 대상은 같은 채널에 있어야 합니다. 시스템 메시지, 읽으면 사라지는 메시지, 이미 그 글타래에 있는 메시지는 옮기지 않습니다. 한 번에 200개까지 옮깁니다.

## 빌드와 설치

```sh
make test   # webapp/node_modules가 필요: npm --prefix webapp ci
make dist   # dist/io.github.sn-kinos.move-to-thread-0.1.0.tar.gz
```

System Console → Plugin Management에서 위 파일을 올리고 켭니다. Mattermost 11.11.1과 12.0.1에서 확인했습니다.
