# Move to Thread

여러 메시지를 골라 다른 메시지의 답글로 한 번에 옮기는 Mattermost 플러그인입니다.

## 쓰는 법

1. 옮길 메시지에 마우스를 올리고 툴바의 체크 상자 버튼(**답글로 옮길 메시지로 선택**)을 누릅니다. 메시지가 강조되고 화면 아래에 선택 막대가 뜹니다.
2. 선택 막대가 떠 있는 동안 같은 채널의 다른 메시지를 누르면 선택에 더하거나 뺍니다. 링크·버튼·이미지를 누르거나 글자를 끌어 고른 경우는 선택으로 치지 않습니다.
3. 답글을 넣을 메시지에 마우스를 올리고 툴바의 + 말풍선 버튼(**선택한 메시지를 여기 답글로 넣기**)을 누릅니다. 선택 막대에서 **옮기기**를 누르면 옮긴 뒤 그 글타래가 오른쪽에 열립니다.

대상이 답글이면 그 글타래의 맨 위 메시지 아래로 넣습니다. 선택한 메시지에 답글이 달려 있으면 그 답글도 함께 옮깁니다. 다른 채널로 가거나 선택 막대의 **취소**를 누르면 선택이 비워집니다. 실패하면 선택은 그대로 두고 막대에 이유를 보여 줍니다.

## 옮기는 방식

Mattermost는 이미 올라간 메시지를 다른 글타래로 바꾸는 API가 없습니다. 그래서 서버가 메시지를 대상 글타래의 답글로 새로 만들고 원본을 지웁니다. Mattermost의 스레드 이동 기능도 같은 방식입니다.

- 작성자, 원래 작성 시각, 본문, 첨부 파일, 반응, 공지 여부를 그대로 둡니다. 첨부 파일은 다시 올리므로 원본이 영구 삭제돼도 남습니다.
- 메시지 ID가 바뀌므로 원본 메시지의 링크는 더 이상 열리지 않습니다. 편집 기록은 옮기지 않습니다.
- 새 답글이 생기므로 글타래를 구독한 사람에게 알림이 갈 수 있습니다.
- 복사하다 하나라도 실패하면 이미 만든 복사본을 지우고 원본은 그대로 둡니다.

## 권한

옮기기는 원본을 지우는 일이라 지울 권한이 있는 메시지만 옮깁니다.

- 옮기는 사람이 그 채널의 멤버이고 글을 쓸 수 있어야 합니다.
- 내 메시지는 `delete_post`, 다른 사람 메시지는 `delete_others_posts` 권한이 있어야 합니다.
- 선택한 메시지와 대상은 같은 채널에 있어야 합니다. 시스템 메시지와 이미 그 글타래에 있는 메시지는 옮기지 않습니다. 한 번에 200개까지 옮깁니다.

## 빌드와 설치

```sh
make test   # webapp/node_modules가 필요: npm --prefix webapp ci
make dist   # dist/io.github.sn-kinos.move-to-thread-0.1.0.tar.gz
```

System Console → Plugin Management에서 위 파일을 올리고 켭니다. Mattermost 11.11.1에서 확인했습니다.
