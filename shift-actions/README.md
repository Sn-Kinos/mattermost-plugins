# Shift Actions

Mattermost 웹앱 플러그인입니다. 메시지에 마우스를 올린 채 Shift를 누르고 있으면 Discord처럼 툴바가 `…`(더 보기) 메뉴의 항목으로 바뀝니다. 원래 툴바 항목(최근 반응, 반응 추가, 저장, 앱 액션, 답글, 더 보기)은 Shift를 누르는 동안 숨겨지고, Shift를 떼면 돌아옵니다.

버튼은 다음과 같습니다(이름은 Mattermost 번역을 그대로 씁니다).

| 버튼 | 동작 | 표시 조건 |
|---|---|---|
| 전달하기 | 전달 창을 엶 | 항상 |
| 메시지·글타래 구독 / 구독 해제 | 스레드 팔로우를 켜고 끔 | 스레드 접기(CRT)가 켜져 있을 때 |
| 안 읽음 표시 | 이 메시지부터 읽지 않음으로 표시 | 항상 |
| 알림 | 더 보기 메뉴를 열어 알림 시간 하위 메뉴를 펼침 | 항상 |
| 공지하기 / 공지 해제하기 | 채널에 고정하거나 해제 | 항상 |
| 텍스트 복사, 링크 복사 | 클립보드에 복사 | 항상 |
| 편집 | 수정 모드로 바꿈 | 내 메시지, 또는 시스템 관리자 |
| 삭제(빨간색) | 확인 창 없이 바로 삭제 | 내 메시지, 또는 시스템 관리자 |

버튼은 같은 메시지의 더 보기 메뉴를 보이지 않게 열고 해당 항목을 대신 누릅니다. 그래서 권한 검사, 토스트, 수정 모드, 전달 창은 Mattermost가 그대로 처리합니다. 삭제는 뜨는 확인 창도 보이지 않게 바로 확인합니다. 메뉴에 없는 항목(예: 권한이 없는 편집)을 누르면 아무 일 없이 메뉴만 닫힙니다.

다른 플러그인이 더 보기 메뉴에 넣은 항목과, 라이선스가 필요한 항목(스레드 이동, 번역 보기, 신고)은 버튼으로 만들지 않았습니다. 이런 항목과 원래 툴바 항목(최근 반응, 반응 추가, 저장, 앱 액션, 답글)은 Shift를 떼고 씁니다.

## 빌드와 설치

```sh
make test   # webapp/node_modules가 필요: npm --prefix webapp ci
make dist   # dist/io.github.sn-kinos.shift-actions-0.1.0.tar.gz
```

System Console → Plugin Management에서 위 파일을 올리고 켭니다. Mattermost 11.11.1에서 확인했습니다.
